ERD Viewer

    See your database as a diagram

    Open a project's .sql files (migrations, schema, seed data). ERD Viewer reads the Postgres CREATE TABLE, ALTER TABLE and INSERT statements and draws the tables and how they connect.

    Your files stay on this device. Nothing is uploaded. On a phone, use “Choose .sql files” and pick them from Files, OneDrive or another app.

    Open a project

    Every .sql file is read in name order (so numbered migrations run in sequence). node_modules and hidden folders are skipped. Files stay on this device.

    Files

    Files are read top to bottom. Untick a file to leave it out. Down and rollback migrations start unticked.
